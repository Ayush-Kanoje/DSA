Problem 3: Digit Extraction

Problem Statement:

Given a positive integer n, write a program to extract and print each digit of the number individually, starting from the units place (rightmost digit) to the most significant digit (leftmost digit).

Input:

A single positive integer n
Output:

Each digit of n printed on a separate line, from rightmost to leftmost.
Example:


Input:  5873

Output:
3
7
8
5
Constraints:

n must be a positive integer (n > 0)
No leading zeros
