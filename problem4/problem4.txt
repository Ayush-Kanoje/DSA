Problem 4: Count the Number of Digits

Given a positive integer n, write a program to count the total number of digits present in the number without converting it to a string.

Input: A single positive integer n
Output: A single integer representing the total count of digits in n
Example:
Input:  n = 546213

Output: 6
Explanation:

546213 → digits are 5, 4, 6, 2, 1, 3 → total = 6
Constraints:

n must be a positive integer (n > 0)
